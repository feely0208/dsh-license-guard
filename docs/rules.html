dsh-license-guard · rules
$ dsh-license-guard --list-rules
 
深鲸守护 · 开源许可合规 —— 5 条规则
 
[high] LIC-GPL
依赖使用 GPL/AGPL 强传染性许可
依据：GNU GPL-2.0/3.0 §5 · AGPL-3.0 §13 —— 分发衍生作品时须以同许可开放源代码
 
[low] LIC-WEAK-COPYLEFT
依赖使用弱传染性许可（需留意）
依据：LGPL-3.0 §4 · MPL-2.0 §3.3 · EPL-2.0 —— 修改该库本身时需以同许可开放
 
[medium] LIC-UNKNOWN
依赖的许可证无法识别
依据：无许可证 = 默认保留全部权利（著作权法默认规则）
 
[medium] LIC-SELF-FILE
项目根目录缺少 LICENSE 文件
依据：著作权法默认规则 —— 未声明许可 = 保留所有权利
 
[low] LIC-SELF-FIELD
package.json 缺少 license 字段
依据：npm 规范 —— license 字段用于下游自动识别许可
